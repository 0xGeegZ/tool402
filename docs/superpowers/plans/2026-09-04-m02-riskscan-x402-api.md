Expose the accepted deterministic RiskScan Quick behavior through one honest x402-protected Next API route while remaining unavailable until a human supplies complete runtime configuration.

## Owned files

- `apps/web/src/app/api/riskscan/route.ts`
- `apps/web/src/lib/riskscan-x402.ts`

## Steps

1. Add a focused RED test for unavailable configuration and an unsigned configured request through the local route boundary.

3. Integrate the local core and pinned x402 packages through root-owned package metadata and lockfile changes.
4. Run focused and full web tests, typecheck, production webpack build, whitespace, and the local-reference guard.
5. Obtain independent review and integrate only the accepted delivery.
