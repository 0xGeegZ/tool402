# UI-S10 guest RiskScan Quick preflight manifest

## Delivery boundary

UI-S10 adds one guest Dashboard local-preflight route and one bounded client
island. It reuses existing local Card, Button, and semantic Link primitives to
make the accepted pure Quick disclosure assessment inspectable before any
unsigned request boundary.

## Local targets

The slice may add `apps/web/src/app/dashboard/riskscan/preflight/page.tsx`,
components under `apps/web/src/components/riskscan/preflight/`, and a focused
preflight test. It may make one constrained Workspace route-map link amendment
and the corresponding focused assertion amendment.

## Truthfulness and authority boundary

The caller explicitly supplies transient request text and declaration states.
The island delegates only to the public local Core Quick function and presents
its local disclosure assessment. It adds no Sign/session/provider/account/
wallet/signer surface; no Agent/API/fetch/request construction, POST, payment
client, storage, configuration, recipient/facilitator, persistence,
receipt/evidence, external link, live claim, or full-tree import. A reported
disclosure is never presented as verification or payment authority.

## Acceptance evidence

- Focused source contracts cover static route semantics, explicit no-default
  form construction, public-Core-only local assessment, truthful outcomes,
  constrained local navigation, and the exclusion boundary.
- Desktop and narrow browser checks cover rendering, explicit interaction,
  polite status feedback, local navigation, keyboard focus, no horizontal
  overflow, and framework/browser diagnostics.
- Web/root quality, production build, queue, guard, independent review, and
  two clean module-review generations pass before acceptance.
