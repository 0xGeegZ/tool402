## Findings

- **[P1] `touch-target` loses the cascade to `min-h-*`.** Location: `src/app/globals.css` `@utility touch-target`, consumed by `ui/button.tsx` sizes `sm` and `md`. Category: Responsive. Impact: under a coarse pointer every Button is 32 or 40px tall, the header "Explore" pill 40px, hero CTAs 32 to 36px; the 44px floor the design system documents is not delivered anywhere a `min-h-*` utility is also present. Standard: WCAG 2.5.5 (AAA) missed; 2.5.8 (AA, 24px) met. Recommendation: replace the utility with Tailwind 4 variants on the Button sizes (`pointer-coarse:min-h-11 pointer-coarse:min-w-11`), which are emitted after the base utilities, and keep `touch-target` only for bare links; pin the compiled order in a test. Command: `/impeccable adapt`.
- **[P2] The 65ch cap skips page-header descriptions and one note.** Location: `ui/page-header.tsx` description (`max-w-3xl`, 768px at 18px, about 85ch); `riskscan/detail/riskscan-detail.tsx` note paragraph (824px at 14px, about 118ch). Category: Implementation integrity. Impact: the longest lines on six routes are the first paragraph a visitor reads. Recommendation: `max-w-prose` on both. Command: `/impeccable typeset`.
- **[P2] Two live regions still mount after the fact.** Location: `provider-deploy-wizard.tsx` validation message, `deploy-stage-signing.tsx` construction error. Category: Accessibility. Impact: the first validation failure on the wizard can be missed by assistive tech. Recommendation: wrap both in `StatusRegion` once #88 (wizard rebuild) lands. Command: `/impeccable harden`.
- **[P2] Five `dl` stat panels still hand-rolled.** Location: `provider-deploy-wizard.tsx` (economics, configuration, review rows), `provider-deploy-stages.tsx` configuration context. Category: Implementation integrity. Recommendation: migrate to `DetailList` after #88 (wizard rebuild) lands. Command: `/impeccable extract`.
- **[P3] Dead card space.** Location: `landing-sections.tsx` `min-h-60`, `min-h-[25rem]`. Recommendation: let content set height. Command: `/impeccable layout`.
- **[P3] Eyebrow count.** 13 uppercase-tracking label sites, nine on `/`. The craft floor bans new ones; the existing set could halve. Command: `/impeccable distill`.
- **[P3] Prefill cannot be cleared.** `?demo=tool-loop` on the tool loop has no in-page reset. Command: `/impeccable onboard`.
